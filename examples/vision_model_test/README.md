# 双模型可视测试 App（实验性）

固定本地视觉测试页，不是 MCP 服务，也未接入 SIoT。

- 同一摄像头帧先完成两个模型推理，再绘制识别框。
- 绿色为姿态分类，橙色为物品分类；Both/Pose/Objects 切换计算模式，Back退出。
- 使用 `/root/models/fall_yolo11.mud` 和 `/root/models/security_yolo11.mud`，需要对应权重；均应为320×320 RGB888输入。模型文件不随本例分发。
- 姿态标签 standing/sitting/lying 不等于摔倒事件或运动识别。
- 目标限频25Hz；界面显示的是实测提交速率，不是光学端到端FPS保证。
- `/tmp/xiaozhi-visual-test/`保存本地指标、状态和预览；不上传摄像头图像。

首版已真机显示且用户确认看到识别框，但界面约13FPS，绘图中位约51.5ms。此处保存最新内置字体/界面缓存优化版：语法和模拟测试通过，已复制到设备，**尚未重新启动完成真机性能验收**。

本例必须经MaixCAM2正常App生命周期运行，避免与其他相机/显示App并行抢占。运行前确认模型文件，退出后确认摄像头归还。程序在导入Maix前清理继承的桌面注入环境；不创建音频采集器、不修改小智服务配置。不要将测试期间的临时单线程KWS结果当作本例的默认运行保证。
