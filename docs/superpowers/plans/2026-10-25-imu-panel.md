# IMU 实时显示与陀螺仪校准实施计划

最终需求：调用 IMU MCP 后实时显示六轴数据；大面板显示 3 秒，然后收起为底部简易数据；补充陀螺仪零偏校准。此需求替代此前的 8 秒静态快照方案。

## 行为约定

- 首次显示使用 `self.imu.read` 返回的同一个样本，随后在当前会话内轮询；采样等待间隔为 0.2 秒，界面刷新目标间隔为 0.5 秒，实际频率受传感器和绘制耗时影响。
- 大面板显示三轴加速度（m/s²）、三轴角速度（°/s）、型号、采样时间、温度可用性及校准状态。3 秒后恢复聊天内容，底栏保留六轴简值、单位和 MCP 工具名称，并继续更新。
- 连续更新不延长大面板计时；重新调用读取则重新开始 3 秒。照片预览优先，拍照原有 3 秒计时不变。
- 关闭弹窗、禁用弹窗或服务、结束会话，以及采样错误，均停止实时读取并清理 IMU 显示；旧会话不能覆盖新会话。
- 新增 `self.imu.calibrate_gyro`、`self.imu.get_calibration`、`self.imu.clear_calibration`，注册工具总数为 29。
- 校准前停止实时读取并等待在途读取结束。设备需在稳定桌面静置，收集约 3 秒、至少 100 个有效样本；明显运动或样本不足拒绝保存并保留原校准。
- 零偏保存到应用自有文件 `/root/xiaozhi/imu_gyro_calibration.json`，原子替换、权限 0600，绑定型号与设备；不调用 SDK 校准，也不修改 SDK 校准文件。
- 校准或清除成功后恢复实时显示。显示失败不应把已成功保存的校准误报为失败。
